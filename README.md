# 삶의 태도 테스트

4가지 축으로 알아보는 16가지 유형 심리 테스트

## 소개

"나는 삶을 어떻게 살고 있을까?"

이 테스트는 삶을 바라보는 태도를 4개의 축으로 분석하여 16가지 유형 중 하나로 알려줍니다.

- **24문항**, 약 **5분** 소요
- MZ세대 맞춤 콘텐츠 (한국 유명인, 드라마/영화 캐릭터 등)

## 4가지 축

| 축 | 설명 | 양극단 |
|---|---|---|
| **욕망** | 삶을 긍정적으로 보고 *싶은가* | 긍정 ↔ 부정 |
| **실제** | 삶을 실제로 긍정적으로 *경험하는가* | 긍정 ↔ 부정 |
| **인식** | 세상에 명확한 기준이 있다고 보는가 | 명확한 기준 ↔ 상황마다 다름 |
| **지향** | 이상을 추구하는가, 현실적으로 선택하는가 | 이상 ↔ 현실 |

## 16가지 유형

### 1번 계열 (삶이 좋고, 실제로도 좋은 사람들)
- **1-A** 열정적 이상주의자
- **1-B** 합리적 낙관주의자
- **1-C** 유연한 이상주의자
- **1-D** 유동적 향유자

### 2번 계열 (크게 기대 안 하지만, 나름 괜찮게 사는 사람들)
- **2-A** 냉철한 원칙주의자
- **2-B** 담담한 현실주의자
- **2-C** 우아한 냉소가
- **2-D** 가볍게 사는 사람

### 3번 계열 (좋은 삶을 원하지만, 현실은 힘든 사람들)
- **3-A** 상처받은 이상주의자
- **3-B** 지친 현실주의자
- **3-C** 아픈 낭만주의자
- **3-D** 살아남은 사람

### 4번 계열 (기대도 낮고, 실제로도 힘든 사람들)
- **4-A** 비관적 진리탐구자
- **4-B** 체계적 비관주의자
- **4-C** 아름다움만 남은 사람
- **4-D** 무감각한 방관자

## A, B, C, D의 의미

| 코드 | 의미 |
|------|------|
| **A** | "정답이 있다" + "이상 추구" → 확고한 신념으로 목표를 향해 |
| **B** | "정답이 있다" + "현실 중심" → 원칙은 있되 실용적으로 |
| **C** | "상황마다 다르다" + "이상 추구" → 열린 마음으로 더 나은 것을 꿈꾸며 |
| **D** | "상황마다 다르다" + "현실 중심" → 유연하게 흘러가며 |
