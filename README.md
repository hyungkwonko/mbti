# 삶의 태도 테스트 | Life Attitude Test

**16가지 실존 유형으로 알아보는 당신의 삶의 태도**

🔗 [테스트 하러 가기](https://hyungkwonko.info/mbti)

## 소개

삶의 태도 테스트는 4개의 축을 기반으로 16가지 실존 유형을 분류합니다:

| 축 | 설명 |
|:---|:---|
| **욕망** | 삶을 긍정적으로 보고 싶은가, 부정적으로 보고 싶은가 |
| **실제** | 실제로 삶을 긍정적으로 경험하는가, 부정적으로 경험하는가 |
| **행동** | 세상에 적극적으로 개입하는가, 소극적으로 개입하는가 |
| **표현** | 내면을 드러내는가, 숨기는가 |

### 기본 4유형

- **1번 계열** (긍정욕망 + 실제긍정): 니체의 운명애, 스토아학파
- **2번 계열** (부정욕망 + 실제긍정): 냉소주의, 키니코스학파
- **3번 계열** (긍정욕망 + 실제부정): 카뮈의 부조리주의
- **4번 계열** (부정욕망 + 실제부정): 쇼펜하우어의 염세주의

## 16가지 유형

| 코드 | 이름 | 철학 |
|:---:|:---|:---|
| 1-A | 전도사형 | 생철학, 긍정심리학 |
| 1-B | 조용한 행동가형 | 스토아, 선종 |
| 1-C | 현자형 | 도가, 에피쿠로스 |
| 1-D | 은자형 | 은둔 스토아, 부정신학 |
| 2-A | 풍자가형 | 키니코스, 풍자문학 |
| 2-B | 마키아벨리스트형 | 마키아벨리즘 |
| 2-C | 데카당스형 | 데카당스, 아이러니즘 |
| 2-D | 냉소적 순응형 | 현대적 시니시즘 |
| 3-A | 혁명가형 | 실존적 마르크시즘 |
| 3-B | 지하운동가형 | 저항적 실존주의 |
| 3-C | 예술가/작가형 | 부조리 문학 |
| 3-D | 고독한 구도자형 | 키르케고르적 실존 |
| 4-A | 철학적 염세형 | 쇼펜하우어, 반출생주의 |
| 4-B | 그노시스형 | 영지주의 |
| 4-C | 비관적 예술가형 | 낭만적 염세, 표현주의 |
| 4-D | 침묵의 체념형 | 무기력한 허무 |
